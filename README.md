# PDF转Word（PdfToWord）- PDF 批量转换 Word 文档

将 PDF 文件批量转换为可编辑的 Word（.docx）文档，保留原文档版式（段落、表格、图片、字体样式）。单文件 exe 打包，**无网络环境双击即用**，无需安装 Python。

打包方式参考 `D:\Programs\BillToExcel`（PyInstaller 单文件 + 一键 bat 脚本）。

## 功能特性

- **批量转换**：添加文件 / 扫描输入目录 / **拖拽 PDF 到窗口**，勾选后一键转换
- **输出可编辑**：Word 中是真实文字，可直接改（不是图片贴图）
- **三模式转换**：
  - 文本层 PDF → pdf2docx 保留版式（段落、表格、图片、字体样式）
  - 扫描件/图片型 PDF → 逐页渲染 + **离线 OCR**（RapidOCR），重建段落为可编辑文字
  - 混合 PDF（文字页+图片页）→ 逐页判断：文字页保留版式，图片页 OCR，合并为单文档
- **完全离线**：OCR 模型与引擎全部打包进 exe，无网络环境可用
- **后台转换**：后台线程执行，界面不卡死，可中途停止
- **进度反馈**：文件级 + **OCR 页级进度**（状态栏显示「OCR 第 x/y 页」）
- **结果表格**：逐文件状态 / 页数 / 输出文件名，状态配色（成功绿 / 失败红 / 转换中蓝 / 警告黄）
- **错误详情**：状态列**悬停提示**完整错误，**点击/右键查看详情**
- **质量检测**：加密 PDF 明确报错；扫描件走 OCR 并提示可能有识别偏差
- **失败重试**：一键重试失败/停止的文件
- **工具栏图标**：添加/扫描/全选/开始/停止/重试/清空均带图标
- **状态栏信息**：版本号、转换模式（版式/OCR）、耗时、拖拽可用标识
- **路径记忆**：输入/输出目录记忆于 `%APPDATA%\PdfToWord`
- **日志面板**：深色终端风格实时日志，可打开输出目录 / 日志文件
- **隐私保护**：日志只记录文件级信息，不记录文档内容；轮转 2MB×5

## 项目结构

```
├── data/                        # 输入: 待转换的 PDF (不入库)

├── pdf_to_word_converter.py     # 核心转换器 PDFToWordConverter
├── run_converter.py             # 命令行入口 (日志/汇总/退出码)

└── README.md
```

## 环境要求

- Python 3.10+
- 运行依赖：pdf2docx / PyMuPDF / python-docx（见 `requirements.txt`）
- 打包依赖：pyinstaller（打包脚本会装进 venv）

安装：

```powershell
pip install -r requirements.txt
```

## 使用方法

### 图形界面（推荐）

```powershell
python gui.py
```

1. 选择**输入目录**（自动列出 PDF）或点「添加文件」
2. 选择**输出目录**
3. 勾选文件 → 点「开始转换」
4. 双击成功行可打开生成的 Word 文档

### 命令行

1. 将 PDF 放入 `data/` 目录
2. 运行：

```powershell
python run_converter.py
```

3. 到 `output/` 取结果；退出码 `0` = 全部成功，`1` = 存在失败文件。

### 打包为 exe（免安装，供无网络人员使用）

**双击 `build_exe.bat`** 即可自动完成打包：

```
venv 不存在 → 自动创建 → 安装依赖 → 生成图标 → 清理旧构建 → PyInstaller 打包
```

产出 `dist\PdfToWord.exe`，**拷贝单个 exe 到目标机器双击即用**，无需 Python、无需网络。首次启动需 1-3 秒解压（`--onefile` 固有行为）。

也可手动执行：

```powershell
python -m PyInstaller --noconfirm --clean PdfToWord.spec
```

> 打包配置统一维护在 `PdfToWord.spec`；exe 中文产品名维护在 `version.txt`。

## 转换流水线

1. **打开**：fitz 打开 PDF；加密 → 报错；空文档 → 报错；损坏 → 报真实错误
2. **页数统计 + 逐页文本层检测**：每页 `get_text()` 判定文本层，区分纯文本 / 纯扫描 / 混合
3. **输出命名**：同名 `.docx`，批内防碰撞（占用时追加 `(2)`、`(3)`…）
4. **转换**：
   - 全部有文本层 → pdf2docx 版式转换（文字可编辑）
   - 全部无文本层（扫描件）→ 每页 200 DPI 渲染 → RapidOCR 离线识别 → 按行距重建段落 → 生成纯文本可编辑 Word（页间分页符）
   - 混合 → 文字页走 pdf2docx 版式、图片页走 OCR，合并为单个 Word；图片页 OCR 无结果时退回嵌入该页原图（照片页不丢失）
5. **校验**：输出文件存在且非空，否则记失败并清理残留

## 测试

```powershell
python -X utf8 -m unittest discover -s tests -v
```

- 单元测试：输出命名、结果结构、缺失/损坏文件报错、批内防碰撞、进度回调
- OCR 测试：`特朗普.pdf` 扫描件 → 断言产出可编辑文字、含关键词、**修改段落后可保存**
- 端到端：程序生成含文本 PDF → 转换 → 断言 docx 存在且正文包含原文
- 集成：`data/` 有真实 PDF 时自动执行端到端断言，无 PDF 自动跳过

## 已知限制

- 扫描件/混合文档 OCR 部分为纯文本重建，版式（分栏/图表位置）不保留；个别字符可能识别偏差
- 混合文档中图片页 OCR 无结果时退回嵌入该页原图（照片页可查看但不可编辑）
- 加密 PDF 需先解除密码
- 复杂版式（多栏、艺术字、嵌套表格）文本层转换可能与原 PDF 存在差异
- OCR 单页约 2-4 秒（离线推理），长文档转换耗时随页数增加
